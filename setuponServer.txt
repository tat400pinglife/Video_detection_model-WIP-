Run:
  sudo apt-get update
  IF ISSUES:
  sudo apt-get install ffmpeg libsm6 libxext6 -y

Step 2
Ensure you are in a virtual environment, then install the required packages.
  pip install -r requirements.txt

If there are some issues with Opencv try the following

  pip uninstall opencv-python-headless opencv-python -y
  pip install opencv-python

Step 3
The dataset scripts require specific folders to exist. The `imported_data` folder may not exist by default. Run these commands from the repository root:
  mkdir -p data/imported_data
  mkdir -p data/videos/real
  mkdir -p data/videos/fake
  mkdir -p data/processed_data/real
  mkdir -p data/processed_data/fake

Step 4
To download the massive ModelScope archives and automatically convert them into tensors, use the local batch processor.

File: `scripts/dataset/process_local_dataset.py`
Inside the file, look for the target URL at the bottom:
  REAL_URL = "https://modelscope.cn/datasets/cccnju/GenVideo-100K/resolve/master/Real_part_aa"

can change the aa to ab and ac for the other parts of the data set if needed
  python scripts/dataset/process_local_dataset.py

Step 5
If you already have a folder full of downloaded .mp4 videos and just want to convert the entire directory into .pt tensors on the GPU, use the bulk processor.

File: `make_tensors.py`
This script recursively searches the input directory (usually `data/videos/real` or `data/videos/fake`), processes every video it finds, and saves the output to the `processed_data` folder.
  1. Open the file and ensure `USE_GPU = True` if you want CUDA acceleration.
  2. Run: `python make_tensors.py`
